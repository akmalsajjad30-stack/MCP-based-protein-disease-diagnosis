# MCP based protein disease diagnosis

An agentic medical assistant (MedRAG) using Model Context Protocol (MCP) and Graph RAG (Neo4j client, Chroma vector database) for protein-disease diagnosis.

## Structure
- `medirag/backend`: FastAPI backend with Neo4j, Chroma vector store, and MCP server integrations.
- `medirag/frontend`: Vite + React UI for visualization, including a results dashboard and interactive knowledge graph.

## Setup & Running
See the scripts and README files in the `medirag` folder for details.
- To start: Use the `start.ps1` script in the `medirag` directory.
