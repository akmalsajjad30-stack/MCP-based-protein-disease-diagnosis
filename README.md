# MCP based protein disease diagnosis

An agentic medical assistant (VeriDX) using Model Context Protocol (MCP) and Graph RAG (Neo4j client, Chroma vector database) for protein-disease diagnosis.

## Structure
- `veridx/backend`: FastAPI backend with Neo4j, Chroma vector store, and MCP server integrations.
- `veridx/frontend`: Vite + React UI for visualization, including a results dashboard and interactive knowledge graph.

## Setup & Running
See the scripts and README files in the `veridx` folder for details.
- To start: Use the `start.ps1` script in the `veridx` directory.
